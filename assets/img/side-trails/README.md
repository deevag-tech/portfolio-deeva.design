# Side trails images

Drop the website stills for the Side trails cards in this folder.

How the card works: the still shows first. If a recording exists, it plays on hover (or tap on phones) and rewinds when you leave.

## Still (this folder)

- Format: WebP (or JPG), 16:10, about 880 x 550 px, under 150 KB
- Crop: the top of the home page, hero visible, no browser chrome
- Names: site-beerbiceps.webp, site-vegapay.webp, site-wishup.webp, site-sketchnote.webp

Already live (in assets/img/): site-astroverse.webp, site-arvind.webp.

## Recording (assets/video/, not this folder)

- Format: WebM (or MP4), muted, no audio, about 10 to 20 seconds, under 6 MB
- Names: for example "BeerBiceps LP.webm", "Vegapay LP.webm"

## After uploading

Tell Claude the file names and it will connect each card.
